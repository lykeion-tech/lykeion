HEIC preview includes libheif 1.23.7 (commit 12a259a5882dd99d45ec5fc77e296a3b620d1e2e) and libde265 1.1.3 (commit ba62bf4cfb3242f3bf0a45617ff09e35236e4d82). They are provided under GNU LGPL v3; their license texts, including GPL v3 terms, are alongside this file. The exact corresponding source archives, the Lykeion wrapper source, and the build script are in source/.

To rebuild or modify the libraries: install Emscripten 4.0.23, CMake 3.31.6 and make; place those tools on PATH, then run source/build.sh. It rebuilds safe-heic.mjs and safe-heic.wasm locally. The build includes libde265 as the sole HEVC codec and caps WASM linear memory at 128 MiB. The original build produced WASM SHA-256 dbe9d6bce828b0b3c338f8fdc646af33f31d3d7a22ccf0c69bd129817264b9b9.

To relink Lykeion with your modified compatible libraries, replace apps/dashboard/src/features/coresearch/viewers/vendor/heic/safe-heic.mjs and safe-heic.wasm in the Lykeion application source tree with the rebuilt files, change HASH in heic-worker.ts to the SHA-256 of the rebuilt WASM, and rebuild the application with npm run build. The wrapper API in preview.c must remain compatible with heic-worker.ts. Changes to the worker or the size limits may be required for other builds. The Lykeion source is available from the project repository. These instructions do not restrict reverse engineering for debugging modifications of the LGPL libraries.
